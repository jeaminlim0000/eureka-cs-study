# 발표 자료와 질의응답 작성 양식

아래 양식을 복사해 사용합니다. 예시 이름과 주차는 실제 배정 내용으로 바꿔주세요.

## 1. 발표 자료

Code → Add file → Create new file에서 `contents/os/주제.md`처럼 분야와 주제에 맞춰 파일을 만듭니다.

```markdown
# 발표 주제

- 작성자: @GitHub아이디
- 발표일: YYYY-MM-DD
- 주차 이슈: 링크
- Discussion: 링크

## 핵심 요약

## 개념과 동작 원리

## 예시와 비교

## 발표 후 보완한 내용
질문으로 발견한 오해나 빠진 설명, 수정한 내용을 기록합니다.

## 참고 자료
- 자료 제목과 출처 링크
```

## 2. 발표 Discussion

Discussions → New discussion → **발표 질의응답**을 선택합니다.

제목: `[Week NN][분야] 발표 주제 — 발표자`

```markdown
## 발표 정보
- 발표자:
- 발표일:
- 주차 이슈:
- 발표 자료:

## 핵심 요약
발표 내용을 2~3문장으로 정리합니다.

## 질문 안내
질문 하나당 새 댓글 하나를 남겨주세요. 한 사람이 여러 질문을 남겨도 됩니다.
답변과 추가 질문은 해당 댓글의 답글로 이어주세요.
현장에서 해결한 질문도 기록으로 남겨주세요.
```

## 3. 질문 댓글

```markdown
### 질문
궁금한 내용을 적습니다.

### 관련 내용
발표의 어느 부분인지, 현재 어떻게 이해했는지 적습니다.
```

## 기록 연결

- 주차 이슈 하나에 4명의 발표 자료와 Discussion을 모두 연결합니다.
- 매주 4명 모두 발표하고, Discussion은 발표마다 하나씩 만듭니다.
- 발표 문서와 Discussion에는 서로의 링크를 넣습니다.
- 답변은 발표자뿐 아니라 다른 팀원도 보충할 수 있습니다.
- 해결되지 않은 질문은 해당 댓글 링크와 확인 담당자를 주차 이슈에 남깁니다.
