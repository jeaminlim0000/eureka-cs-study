# Week09 DB RDB 기초

> 일자: 2026.09.08 · 관련 Issue: [#10](https://github.com/jeaminlim0000/eureka-cs-study/issues/10)

## 발표 기록 상태

노션에는 Key, Join, Normalization, SQL Injection 커리큘럼만 있고 발표자 배정·질의응답 기록은 남아 있지 않습니다.

## 함께 다룬 핵심 주제

- Primary Key와 Foreign Key로 행 식별과 테이블 관계를 표현합니다.
- Join은 관계 키를 기준으로 여러 테이블을 연결합니다.
- 정규화는 중복과 수정 이상을 줄이기 위해 데이터를 역할별로 분리합니다.
- SQL Injection은 사용자 입력을 SQL 문자열로 이어 붙일 때 생기며, PreparedStatement·파라미터 바인딩으로 막습니다.
