# Week07 Network TCP/IP

> 일자: 2026.08.18 · 관련 Issue: [#8](https://github.com/jeaminlim0000/eureka-cs-study/issues/8)

## 발표·학습 구성

- 현빈: OSI
- 서희: TCP
- 정현: UDP
- 재민: 3-way Handshake

## 함께 정리한 내용

- OSI는 통신 과정을 계층으로 나눈 참조 모델이며, 장애를 계층별로 좁혀 진단하는 공통 언어입니다.
- TCP는 연결 지향·신뢰성 전송을 제공하고, UDP는 연결 설정·재전송 비용이 작아 실시간 전송에 활용됩니다.
- TCP 연결은 SYN → SYN/ACK → ACK의 3-way Handshake로 시작합니다.

## 기록 상태

노션에는 OSI 상세 설명만 남아 있고 TCP·UDP·Handshake의 세부 발표 본문은 누락되어 있습니다.
