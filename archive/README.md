# Week01~10 과거 스터디 기록

이 폴더는 GitHub 운영 이전에 노션과 스터디 자리에서 남긴 기록을 주차별로 옮긴 아카이브입니다.

- `contents/`는 Week11 이후 발표자가 직접 작성하는 발표 자료를 보관합니다.
- `archive/`는 과거 주차의 공통 발표·질의응답 요약을 보관합니다.
- 노션에 없는 발표자 배정이나 세부 답변은 추측으로 채우지 않고, `확인 필요`로 표시합니다.
