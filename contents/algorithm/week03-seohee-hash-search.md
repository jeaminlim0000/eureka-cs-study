## Hash Table

Hash Table은 Key를 해시 함수에 넣어 저장 위치를 계산하는 자료구조입니다. 평균적으로 조회·삽입·삭제가 O(1)이지만, 충돌이 많이 나면 O(N)까지 느려질 수 있습니다.

Java `HashMap`에서 사용자 정의 객체를 Key로 쓸 때는 `equals()`와 `hashCode()`를 함께 재정의해야 합니다. 같은 객체로 판단되는 두 값은 같은 해시값을 가져야 올바른 버킷에서 찾을 수 있습니다.

## BFS · DFS · DP

- BFS는 Queue를 사용해 가까운 노드부터 탐색하므로, 가중치가 같은 그래프의 최단 거리 탐색에 적합합니다.
- DFS는 한 경로를 깊게 탐색하며 재귀나 Stack으로 구현합니다. 경로 탐색, 연결 요소 수, 사이클 검사에 자주 사용합니다.
- DP는 반복되는 작은 문제의 결과를 저장해 재사용하는 방식입니다. Memoization은 Top-down, 테이블 채우기는 Bottom-up 구현에서 자주 사용합니다.

BFS는 시작점에서 거리가 1인 노드, 2인 노드 순서로 탐색하므로 처음 목적지에 도착한 경로가 최소 간선 수를 보장합니다. DFS는 깊은 경로를 먼저 선택하므로 최단 경로를 보장하지 않습니다.
