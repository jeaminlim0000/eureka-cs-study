# Key · Join · Normalization · SQL Injection — 공동 기록

> Week09 · 2026.09.08 · [Issue #10](https://github.com/jeaminlim0000/eureka-cs-study/issues/10)

발표자 배정과 세부 질의응답은 남아 있지 않아 공동 기록으로 보관합니다.

Primary Key는 행을 식별하고 Foreign Key는 테이블 관계를 표현합니다. Join은 관계 키로 여러 테이블을 연결합니다. 정규화는 중복과 수정 이상을 줄이며, SQL Injection은 PreparedStatement와 파라미터 바인딩으로 방어합니다.
