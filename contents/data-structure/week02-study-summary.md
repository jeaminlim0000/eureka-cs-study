## Tree · BST · Heap

트리는 부모와 자식 관계로 계층 데이터를 표현하는 비선형 자료구조입니다. 파일 시스템처럼 폴더 안에 폴더가 있는 구조를 표현하기 좋습니다.

BST(Binary Search Tree)는 왼쪽 서브트리의 값이 부모보다 작고 오른쪽 서브트리의 값이 부모보다 큰 규칙을 가집니다. 균형 잡힌 상태에서는 탐색·삽입·삭제가 O(log N)이지만, 정렬된 값이 계속 들어오면 한쪽으로 치우쳐 O(N)이 될 수 있습니다.

Heap은 완전 이진 트리이며 부모와 자식 사이의 우선순위만 보장합니다. Min Heap은 최솟값, Max Heap은 최댓값을 루트에서 O(1)에 확인할 수 있고 삽입·삭제는 O(log N)입니다.

## Java 연결

Java의 `PriorityQueue`는 Heap 기반입니다. 작업 우선순위, 가장 빠른 마감 시간, 상위 N개 데이터처럼 항상 최솟값 또는 최댓값을 빠르게 꺼내야 할 때 사용합니다. 전체가 정렬된 구조는 아니므로 임의 값 탐색에는 적합하지 않습니다.

## 확인 질문

**Heap과 BST의 목적 차이를 설명해 주세요.**  
BST는 정렬 규칙을 이용해 특정 값을 탐색하는 데 적합하고, Heap은 루트의 최고·최저 우선순위 값을 빠르게 꺼내는 데 적합합니다. Heap은 좌우 형제 간 순서까지 보장하지 않으므로 일반 탐색에는 느립니다.
