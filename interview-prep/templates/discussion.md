# Discussion 글과 댓글 양식

한 글에 공통 주제 하나를 다룹니다. 주제 번호는 그 주의 README에 나온 순서를 따릅니다.

## 출제자가 올릴 글

제목 예시 `[01주차][주제 2] IoC와 생성자 주입 · octocat`

```markdown
## 기본 질문

개념이나 동작 원리를 묻는 질문 하나를 적습니다.

## 응용 질문

직접 작성한 코드나 실무 상황과 연결한 질문 하나를 적습니다.

## 관련 자료

개념 노트나 질문에 필요한 코드 링크를 붙입니다.
```

## 팀원이 남길 첫 답변

```markdown
**기본 질문 답변**

**응용 질문 답변**

**판단 근거 또는 아직 확실하지 않은 부분**
```

## 두 사람의 첫 답변 후 출제자가 남길 댓글

```markdown
**AI 참고 답변 · 기본 질문**

**AI 참고 답변 · 응용 질문**

**확인한 근거**

검토한 공식 문서나 코드 실행 결과를 붙입니다. 확인이 필요한 부분은 표시합니다.
```

## 참고 답변을 본 뒤 답변자가 남길 댓글

```markdown
**처음에 이렇게 생각한 이유**

**놓친 조건이나 다르게 해석한 부분**

**수정한 답변과 확인 근거**
```
