# 종합 복습 · 프로젝트 모의면접

[8주차로 돌아가기](README.md)

## 기본 질문

1. **기본** · 프로젝트를 1분 안에 소개하고, 어떤 문제를 풀었으며 본인이 맡은 범위가 어디인지 설명해 주세요.
2. **내 코드** · 직접 작성한 기능의 요청부터 응답까지 따라가며, 가장 고민한 선택과 실제로 확인한 테스트나 로그를 보여주세요.
3. **상황** · 본인 기능의 응답 시간이 배포 뒤 늘었습니다. 어느 범위에서 늘었는지 확인하고, 해당 변경이 원인이라는 가설을 어떻게 검증하겠어요?

## 추가 질문

1. 가장 어려웠던 버그는 무엇이었나요? 재현 방법, 초기 가설, 실제 원인, 수정 후 검증 순서로 설명해 주세요.
2. 당시 고려한 대안은 무엇이었나요? 어떤 제약 때문에 지금의 구현을 선택했나요?
3. 직접 작성한 테스트 하나가 보장하는 동작과 실패해야 하는 조건은 무엇인가요?
4. 같은 요구사항을 다시 구현한다면 무엇을 먼저 바꾸겠어요? 실제로 확인한 한계와 예상 효과를 어떻게 구분하나요?
5. 사용량이 늘면 어디부터 측정하겠어요? 병목 후보로 고른 이유는 무엇인가요?
6. 외부 서비스가 실패하면 사용자는 어떤 응답을 받나요? 그 동작을 어디에서 검증했나요?
7. TEL-ME 경험이 있다면 상담, 검색, LLM 호출, 개인정보 처리 중 맡은 기능 하나에서 정상 흐름과 실패 흐름을 설명해 주세요.
