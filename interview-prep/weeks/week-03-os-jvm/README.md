## 출제 예시

1. **기본** · 프로세스와 스레드는 무엇을 각각 가지고, 같은 프로세스에서 무엇을 공유하나요?
2. **내 코드** · Java 메서드의 지역 변수에 저장된 참조와 그 참조가 가리키는 객체가 어떻게 다른지 본인 코드에서 설명해 주세요.
3. **상황** · 프로그램이 처음 큰 데이터를 읽을 때 느리고 두 번째는 빠릅니다. 페이지 폴트와 파일 캐시의 관점에서 어떤 가설을 세우고 확인하겠어요?

## 추가 질문은행

1. 컨텍스트 스위칭 때 어떤 실행 상태를 저장하고 복원하나요? 왜 비용이 드나요?
2. 가상 주소와 물리 주소의 차이는 무엇이고, 페이지 테이블은 어떤 역할을 하나요?
3. 페이지 폴트는 언제 발생하나요? 모든 페이지 폴트가 디스크 읽기로 이어지나요?
4. JVM에서 호출 스택과 힙은 각각 어떤 역할을 하나요?
5. GC는 회수할 객체를 어떻게 판단하나요? 더 이상 쓰지 않는 객체가 계속 힙에 남을 수 있나요?
6. 힙 사용량과 API 지연이 동시에 올랐습니다. GC 로그와 힙 덤프로 각각 무엇을 확인하겠어요?
