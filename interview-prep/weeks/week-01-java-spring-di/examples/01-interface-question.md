# [면접 01주차][주제 1] 인터페이스와 다형성

## 기본 질문

인터페이스 타입으로 메서드를 호출하면 어떤 객체의 구현이 실행되나요? 인터페이스를 사용하면 호출하는 코드와 구현체의 관계가 어떻게 달라지는지 설명해 주세요.

## 응용 질문

본인이 작성한 코드에서 인터페이스를 사용한 곳이 있나요? 어떤 기능이었고, 호출하는 클래스와 구현 클래스를 왜 나눴는지 설명해 주세요.

직접 사용한 경험이 없다면, 발송 방식을 이메일에서 문자로 바꿀 수 있어야 하는 알림 기능을 예로 들어 어떤 인터페이스와 의존 관계를 만들지 설명해 주세요.

## 답변 방법

면접에서 말하듯 핵심부터 설명해 주세요. 코드 경험은 클래스나 메서드 하나를 골라 동작과 선택 이유를 설명해 주세요. 다른 두 분이 먼저 답한 뒤 참고 답변을 공유하겠습니다.
