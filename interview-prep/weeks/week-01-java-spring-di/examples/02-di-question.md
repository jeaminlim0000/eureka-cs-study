# [면접 01주차][주제 2] IoC와 생성자 주입

## 기본 질문

DI란 무엇인가요? 서비스가 의존 객체를 직접 생성하는 방식과 생성자로 전달받는 방식은 어떻게 다른가요?

## 응용 질문

본인이 작성한 서비스에서 생성자 주입을 사용한 지점을 설명해 주세요. 어떤 의존 객체를 받고, 그 객체가 실제로 어디에서 등록되고 어떻게 전달되는지도 말씀해 주세요.

직접 사용한 경험이 없다면, 외부 API 클라이언트에 의존하는 서비스를 예로 들어 어떤 객체를 생성자로 받고 실패 응답을 테스트하려면 무엇을 전달할지 설명해 주세요.

## 답변 방법

기능, 코드에서 사용한 위치, 선택 이유 순서로 설명해 주세요. 실제로 작성한 테스트가 있다면 어떤 입력과 결과를 확인했는지도 덧붙여 주세요. 다른 두 분이 먼저 답한 뒤 참고 답변을 공유하겠습니다.
