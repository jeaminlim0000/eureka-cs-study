# [면접 01주차][주제 3] Spring 빈 등록과 주입 대상 선택

## 기본 질문

Spring 빈은 무엇이고, 어떤 방식으로 등록할 수 있나요? 생성자가 하나인 빈은 어떻게 의존 객체를 전달받나요?

## 응용 질문

서비스가 인터페이스 타입의 의존성을 생성자로 받습니다. 새 구현 클래스를 빈으로 등록한 뒤 앱이 시작하지 않고 해당 타입의 주입 후보가 여러 개라는 오류가 발생했습니다.

무엇을 먼저 확인하고, 어떤 기준으로 주입 대상을 선택하겠어요? `@Primary`와 `@Qualifier`를 각각 어떤 경우에 선택할지 설명해 주세요.

## 답변 방법

주어진 오류가 무엇을 의미하는지 먼저 설명하고, 확인할 코드와 설정을 말씀해 주세요. 다른 두 분이 먼저 답한 뒤 참고 답변을 공유하겠습니다.
