1. 시간 복잡도와 배열·연결 리스트
2. 스택·큐·우선순위 큐
3. `HashMap`과 `equals()`·`hashCode()`

세 주제 모두를 각자의 `notes/<GitHub-ID>.md` 한 파일에 정리합니다. 각자 주제별 Discussion 글을 하나씩 열고 글마다 기본 질문 1개와 응용 질문 1개를 올립니다.

## 출제 예시

1. **기본** · List, Set, Map을 순서, 중복, 조회 방식에 따라 어떻게 고르나요?
2. **내 코드** · 본인이 작성한 컬렉션 처리 코드에서 그 자료구조를 고른 이유와 중복을 판단하는 기준을 설명해 주세요.
3. **상황** · HashMap에 넣었던 키로 값을 다시 찾지 못합니다. 키의 필드가 변경됐다면 어떤 메서드와 데이터를 확인하겠어요?

**공부할 때 확인할 점** · 키의 해시 계산에 쓰이는 필드를 바꾸는 작은 예제를 만들고, 변경 전후 get()의 결과를 실행 전에 예측해 봅니다.

## 추가 질문은행

1. 기본형과 참조형에서 ==는 무엇을 비교하나요? equals()는 어떻게 다른가요?
2. 객체를 메서드에 넘길 때 무엇이 복사되나요? 매개변수 재할당과 객체 필드 수정은 어떻게 다른가요?
3. final 참조와 불변 객체는 어떻게 다른가요? record가 가변 리스트를 담으면 어떤 점을 고려해야 하나요?
4. String은 왜 불변인가요? 반복문에서 StringBuilder를 쓰는 이유는 무엇인가요?
5. ArrayList와 LinkedList의 인덱스 접근과 삽입·삭제 비용은 어떻게 다른가요?
6. HashMap은 해시 충돌을 어떻게 처리하나요? equals()와 hashCode() 사이에 어떤 규약이 있나요?
7. HashMap, LinkedHashMap, TreeMap의 순회 순서는 어떻게 다른가요?
8. List<Integer>를 List<Number>에 대입할 수 있나요? 와일드카드는 언제 쓰나요?
9. Stream의 중간 연산과 최종 연산은 무엇인가요? 반복문을 선택할 기준은 무엇인가요?
10. Checked exception과 unchecked exception의 차이는 무엇인가요? try-with-resources는 무엇을 정리하나요?
11. 시간 복잡도에서 O(1), O(log n), O(n)은 무엇을 뜻하나요? 자료가 늘어날 때 어떻게 달라지나요?
12. 스택과 큐의 차이는 무엇인가요? 자바에서는 각각 어떤 자료구조를 사용할 수 있나요?
13. FIFO 큐와 우선순위 큐는 어떤 기준으로 원소를 꺼내나요? 어떤 문제에 적합한가요?
